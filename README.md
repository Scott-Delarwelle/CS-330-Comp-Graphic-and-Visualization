# CS-330-Comp-Graphic-and-Visualization
CS 330 Computational Graphics and Visualization Portfolio
1. How do I approach designing software?
    • What new design skills has your work on the project helped you to craft?
Working on the 3D scene project allowed me to get significant experience in spatial organization, rendering pipelines, and architectural planning.
    • What design process did you follow for your project work?
The task involved a well-defined design process, including developing the scene layout, designing the code structure in documentation, and implementing geometry, textures, and lighting one after another.
    • How could tactics from your design approach be applied in future work?
The techniques I have learned in this project could be transferred to subsequent software development projects, where it is essential to plan and organize the code architecture to optimize performance. In particular, the project showed that complicated systems are better divided into simple components and that it is always necessary to maintain an orderly structure within the software.
2. How do I approach developing programs?
    • What new development strategies did you use while working on your 3D scene?
When working on the 3D scene, I used various approaches and methods, including writing my own GLSL shaders, using vertex buffer/array objects, and implementing the Phong reflection model.
    • How did iteration factor into your development?
In this project, I learned through iterations, as working on the scene required trial and error to balance the code and visual display. I had to constantly make adjustments to the coordinates, materials, and light vector positions to see how changes influenced the image.
    • How has your approach to developing code evolved throughout the milestones, which led you to the project’s completion?
From the beginning to the end, my understanding of what happened in the code fundamentally changed. If I saw graphics as a black box before, now I had some clear understanding of what happened in a particular fragment or vertex shader. In particular, working with the 3D scene improved my understanding of how memory structures, mathematical models, and algorithms form the basis of software systems.

As a result, now I can take more challenging courses on computer systems, software development, and systems programming.

At the same time, this knowledge is also helpful in my profession since optimizing and debugging code is the basis for working with simulations, applications, and software in general.
